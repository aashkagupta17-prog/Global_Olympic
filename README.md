# Global_Olympic
# Global Olympic Sports Performance Analysis

## 1. Introduction
The Olympic Games provide a global platform for evaluating sporting achievements across countries, regions, and sports categories. This project uses Tableau Desktop to analyze Olympic performance data from 1992 to 2026 through interactive charts, dashboards, and stories.

## 2. Objectives
- Analyze country-wise gold, silver, bronze, and total medal counts.
- Identify trends in medals awarded across Olympic Games.
- Compare athlete participation and sport category performance.
- Analyze medal efficiency across different regions.
- Explore the relationship between sports investment categories and medal outcomes.
- Compare recorded medal performance for host nations.

## 3. Tools and Technologies
- Tableau Desktop — data visualization and dashboard development.
- CSV datasets — data storage and input.
- Tableau Calculated Fields — derived metrics and categories.
- Tableau Filters and Parameters — interactive analysis.
- Tableau Story — presenting insights in a logical sequence.

## 4. Datasets Used
1. alltime_country_rankings.csv
2. athletes.csv
3. games_summary.csv
4. medal_results.csv

## 5. Methodology
The project follows data collection, data validation, preparation, visualization, dashboard development, story creation, and performance testing. The datasets are analyzed at their appropriate levels to avoid duplication and incorrect aggregations.

## 6. Key Visualizations
- Top 10 Countries by Total Medals
- Gold, Silver and Bronze Medal Comparison
- Total Medals Awarded Over the Years
- Average Medals per Athlete by Sport Category
- Investment Category Analysis
- Regional Medal Efficiency
- Host Country Performance
- Athlete Participation by Gender

## 7. Expected Outcomes
The dashboards provide an interactive view of Olympic medal performance, athlete participation, sport categories, regional patterns, and investment classifications. The analysis can help stakeholders identify patterns and formulate questions for further research.

## 8. Conclusion
The project demonstrates how Tableau Desktop can convert structured Olympic datasets into interactive visualizations that support data exploration and evidence-based decision-making. All conclusions are based on the available dataset and its limitations.
